# Changelog

## 0.1.0 — 2026-10-30 (Public preview)

First public preview; compatibility testing across systems and applications is ongoing.

- Added configurable post-shake hold duration (default 0.35 seconds).
- Added built-in Chinese and English selected by Windows display language.
- Settings apply immediately and save automatically.
- Default sensitivity is 0.8; each slider has a Default button and numeric input.
- Refined the compact settings layout and clarified slider descriptions.
- Wheel up increases slider values; wheel down decreases them.
- Added MIT licensing, publishing documentation and source/portable packaging.
- Unified application and package versioning through the root VERSION file.
